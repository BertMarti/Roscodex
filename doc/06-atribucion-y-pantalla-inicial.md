# Atribución, créditos y pantalla inicial

## Objetivo

Informar de que es un proyecto fan y mostrar las fuentes utilizadas sin invadir la pantalla de inicio.

## Texto corto visible

```text
Proyecto fan no oficial de Pokémon.
Sin afiliación ni patrocinio oficial.

[Más información y fuentes]
```

## Texto ampliado sugerido

```text
Roscodex es un proyecto fan no oficial creado con fines educativos y de experimentación.

Pokémon y los nombres de sus personajes pertenecen a sus respectivos titulares. Este proyecto no está afiliado, patrocinado ni aprobado por Nintendo, Creatures Inc., GAME FREAK inc. ni The Pokémon Company.

Fuentes consultadas:
• PokéAPI — https://pokeapi.co/
• PokéAPI sprites — https://github.com/PokeAPI/sprites

Las preguntas del proyecto son redactadas y revisadas para esta demo. Cuando se utilicen datos externos, se conservará la fuente y la fecha de consulta en los metadatos internos.
```

Si se usa Open Trivia DB, añadir:

```text
• Open Trivia DB — https://opentdb.com/
• Los datos de Open Trivia DB se distribuyen bajo CC BY-SA 4.0 según su documentación.
```

## Comportamiento UX

- Mostrar el texto corto en la pantalla inicial.
- Colocar un botón con icono de información.
- Abrir un diálogo o bottom sheet.
- Permitir cerrar con un botón claro.
- No obligar a leer los créditos para empezar a jugar.
- Mantener enlaces de fuente seleccionables.

## Política de recursos

Para la demo local se pueden probar sprites servidos por PokéAPI, pero se debe registrar de dónde procede cada recurso. Para compartir o distribuir el proyecto, revisar de nuevo permisos, marcas y condiciones. La existencia de una API gratuita no equivale a una licencia general sobre los personajes representados.

La documentación oficial de Pokémon contiene restricciones sobre el uso de sus materiales: [Pokémon — información legal](https://www.pokemon.com/es/legal/informacion) y [Pokémon Support — uso de imágenes o materiales](https://support.pokemon.com/hc/en-us/articles/360000634094-Can-I-use-Pok%C3%A9mon-images-or-materials).
