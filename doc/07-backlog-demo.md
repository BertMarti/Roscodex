## Primera sesión de desarrollo

1. Instalar Flutter y ejecutar `flutter doctor`.
2. Crear el proyecto.
3. Ejecutar la plantilla en un emulador.
4. Crear `assets/data/questions.json` con tres preguntas.
5. Crear la pantalla de dificultades.
6. Conectar una dificultad a una partida de tres letras.
7. Confirmar que el flujo completo funciona.
